# Security policy

## Supported versions

`identity-stack` has no supported releases yet. The repository is still in its
documentation and architecture phase, but reports about security concerns in
the current repository are welcome.

## Report a vulnerability privately

Use [GitHub Private Vulnerability Reporting](https://github.com/suazithustra/identity-stack/security/advisories/new)
for this repository. This is the only reporting path published by the project.
Do not disclose vulnerability details in a public issue, discussion, pull
request, or other public channel.

Include enough information for the maintainers to understand and reproduce the
problem without adding real credentials or unrelated sensitive data:

- the affected file, component, interface, or deployment profile;
- the observed behavior and expected security behavior;
- reproduction steps or a minimal proof of concept;
- the conditions, configuration, and artifact identities involved;
- the potential impact and any known exploitation prerequisites; and
- suggested mitigations or supporting evidence, when available.

Maintainers will keep the report in the private advisory, acknowledge it there,
assess the affected scope, request clarification when needed, and coordinate
remediation and disclosure with the reporter. Response and remediation timing
depends on the report's severity, complexity, and affected dependencies; the
project does not publish a fixed response deadline at this stage.
